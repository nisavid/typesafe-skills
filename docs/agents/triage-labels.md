# Triage labels

| Role and label | Meaning |
| --- | --- |
| `needs-triage` | Maintainer needs to evaluate the issue. |
| `needs-info` | More information is needed from the reporter. |
| `ready-for-agent` | The work is specified for an agent to carry out. |
| `ready-for-human` | Human implementation is required. |
| `wontfix` | The work will not be pursued. |

Wayfinder maps and child tickets use only their `wayfinder:*` labels.
